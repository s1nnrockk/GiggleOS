# GiggleOS

**GiggleOS** — проект полноценной Android-based мобильной операционной системы на базе AOSP.

Цель проекта — создать собственную систему с узнаваемым интерфейсом, системными приложениями, обновлениями и поддержкой нескольких устройств через отдельные device-порты.

> **Статус:** ранняя стадия проектирования. Рабочая прошивка и установочные образы пока не выпущены. Не устанавливайте неподтверждённые образы на телефон.

## Цели

- Полноценная Android-система, а не только лаунчер или APK-оболочка.
- Общая платформа GiggleOS и отдельные конфигурации для каждой модели телефона.
- Собственный интерфейс, настройки и системные приложения.
- Проверяемые сборки и публикация релизов через GitHub Actions там, где хватает ресурсов CI.
- Документированные требования, проверка совместимости и безопасный процесс обновления.

## Архитектура

- **Основа:** Android Open Source Project (AOSP).
- **Низкий уровень:** Linux kernel, HAL, device tree и vendor-компоненты конкретного устройства.
- **Системный интерфейс:** Android System UI и собственные системные компоненты.
- **Приложения:** Kotlin/Java и Android SDK.
- **Сборка:** официальные инструменты AOSP/Soong; device-specific конфигурации.
- **Релизы:** подписанные образы и контрольные суммы после успешной сборки и тестирования.

## Первый целевой телефон

Предварительная цель — Xiaomi Redmi Note 8 (codename: ginkgo). Redmi Note 8T имеет другое имя устройства — willow; Redmi Note 8 2021 — biloba. Перед подготовкой образа модель необходимо подтвердить по точному номеру модели и аппаратной ревизии.

## Поддержка устройств

GiggleOS не будет использовать один универсальный ZIP для всех телефонов. Каждая модель требует отдельной проверки загрузчика, разметки разделов, ядра, драйверов, vendor blobs и аппаратных функций. Новые устройства добавляются отдельными портами и проходят тестирование до публикации.

См. [матрицу устройств](docs/DEVICE_SUPPORT.md) и [план разработки](docs/ROADMAP.md).

## Безопасность

- Не публиковать образы как стабильные, пока они не прошли проверку.
- Не использовать образ, предназначенный для другой модели или варианта устройства.
- Перед экспериментами сохранить личные данные и убедиться, что существует проверенный способ восстановления.
- Не обходить блокировки и проверки совместимости установщика.

## Лицензии

GiggleOS будет содержать компоненты AOSP и сторонние компоненты с разными лицензиями. Лицензии и уведомления каждого включённого компонента должны сохраняться; собственные файлы проекта будут лицензироваться отдельно после выбора лицензии проекта.
