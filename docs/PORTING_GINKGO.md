# Историческая заметка: Redmi Note 8 (ginkgo)

> **Не использовать как план первого порта GiggleOS.** Первый целевой телефон подтверждён как Xiaomi Redmi Note 8 Pro (`begonia`). Для него ведётся отдельное исследование: [PORTING_BEGONIA.md](PORTING_BEGONIA.md).

Эта заметка сохранена, чтобы не потерять ранее собранные сведения. Она относится только к стандартному Redmi Note 8 и не применима к Redmi Note 8 Pro.

## Аппаратная справка

Стандартный Redmi Note 8 использует Qualcomm Snapdragon 665 (SM6125) и GPU Adreno 610. Эти характеристики нельзя переносить на Redmi Note 8 Pro, который построен на MediaTek Helio G90T.
