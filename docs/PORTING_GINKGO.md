# Исследование первого порта: Redmi Note 8 family

## Текущий статус

**Research only — GiggleOS не собрана и не проверена на устройстве.** Первый кандидат — Xiaomi Redmi Note 8 (`ginkgo`). Точная модель телефона пользователя пока неизвестна.

## Аппаратная справка

Для стандартного Redmi Note 8 документация LineageOS указывает Qualcomm Snapdragon 665 (SM6125), GPU Adreno 610 и варианты 3/4/6 ГБ RAM. Эти характеристики нельзя автоматически переносить на Redmi Note 8 Pro или Redmi Note 8 (2021).

## Upstream-ориентир

- LineageOS device page: https://lineageos.github.io/lineage_wiki/devices/ginkgo/variant1/
- Build guide: https://blob.lineageos.org/preview/wiki/506566/devices/ginkgo/build/variant1/
- В просмотренной документации для ginkgo указана ветка `lineage-24.0`.
- Документация LineageOS перечисляет варианты Redmi Note 8 и Redmi Note 8T для семейства ginkgo. Перед выбором target обязательно сверить вариант и номер модели.

Это upstream-справка для изучения совместимости, а не заявление, что GiggleOS уже поддерживает эти устройства. Соблюдать лицензии upstream device/kernel/vendor компонентов и сохранять требуемые уведомления.

## Следующие инженерные задачи

1. Получить точный номер модели из «Настройки → О телефоне → Подробная информация и характеристики».
2. Подтвердить codename и аппаратный вариант по нескольким независимым признакам.
3. Зафиксировать точный upstream manifest/branch и ревизии device, kernel и vendor repositories.
4. Изучить требования к версии firmware, разметке разделов, recovery и boot image.
5. Подготовить отдельную конфигурацию продукта GiggleOS, не меняя пока загрузочные разделы телефона.
6. Организовать воспроизводимую сборку в Linux build environment и сохранить логи.
7. Сначала проверить результат в безопасной тестовой среде и на отдельном тестовом устройстве; только затем планировать аппаратные испытания.

## Не делать

- Не угадывать модель по внешнему виду или названию в магазине.
- Не смешивать ginkgo, biloba и begonia.
- Не публиковать универсальный ZIP.
- Не объявлять образ готовым к установке до прохождения полного набора тестов и проверки восстановления.
