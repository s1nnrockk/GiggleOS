# Матрица поддержки устройств

## Правила добавления устройства

Каждый порт должен иметь собственный идентификатор устройства, конфигурацию сборки и проверенные зависимости. Минимальный набор проверки:

- точный коммерческий вариант и номер модели;
- codename и SoC;
- схема разделов и тип A/B или A-only;
- совместимая версия firmware/vendor;
- device tree, kernel tree и vendor blobs с понятным происхождением и лицензиями;
- работа дисплея, сенсорного ввода, звука, Wi-Fi, Bluetooth, мобильной сети, камер, датчиков, GPS и зарядки;
- проверка загрузки, перезагрузки, шифрования и обновления;
- опубликованные контрольные суммы и инструкции восстановления.

Наличие device tree в стороннем проекте не означает, что порт GiggleOS уже готов или проверен.

## Статусы

| Устройство | Codename | Статус |
|---|---|---|
| Xiaomi Redmi Note 8 | ginkgo | Первый кандидат; модель пользователя требует подтверждения |
| Xiaomi Redmi Note 8T | willow | Отдельный вариант; не считать взаимозаменяемым без проверки |
| Xiaomi Redmi Note 8 (2021) | biloba | Отдельная аппаратная платформа; отдельный порт |

Все остальные устройства: **не заявлены / не тестировались**.

## Важное замечание

Не использовать образ ginkgo на willow или biloba только потому, что названия телефонов похожи. Сначала подтвердить точную модель и аппаратную ревизию.
